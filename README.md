## “优化线路”到底在优化哪一段

国内访问海外服务器，数据走两段路。去程是你发请求时从国内出去走的线，回程是服务器把网页、图片、文件传回来走的线。打开一个页面，绝大部分字节在回程上，所以回程质量对体感的影响远大于去程。

普通国际带宽走 163 骨干网，晚高峰拥堵是常态，丢包和延迟抖动都在这个时段集中出现。优化线路走的是另一批通道：电信 CN2 GIA 的 59.43 网段、联通 9929、移动 CMIN2。它们贵在绕开了拥堵节点。

AkkoCloud 法兰克福机房的配置是电信联通去程走 CN2 GIA，移动去程走 CMIN2 或直连，三网回程统一走电信 CN2 GIA 链路。也就是说移动用户去程没走自家精品线，但回程仍然落在 GIA 上，实际体验不会因为去程直连而明显吃亏。
